# 莫比奥尔斯机

## 纸带系统

莫比奥尔斯机是一种图灵机变体，读写头在无限长的数字数据纸带上双向移动。机器分为程序纸带和数据纸带。

### 程序纸带

- 指令通过程序纸带送入，程序纸带单向顺序只读，通过物理连接程序纸带两端实现程序循环，这种循环是可选的
- 程序纸带按序列轮回调度，如一个三程序纸带的序列，换带按照1、2、3、1的顺序。若只有单个程序纸带，则执行换带指令为从头执行自身。
- 当执行换带指令时，停机，保留当前读写头位置和数据纸带数据，切换到下一个程序纸带开始从头读取，而上一条程序纸带的PC状态丢失
- 可以在程序开始前向队列里插入任意数量的程序纸带，程序开始后则只能由程序自身向队列里添加程序纸带
- 支持将当前的数据纸带从读写头右侧截断，取截下来的左侧数据纸带片段作为新的程序纸带插入当前程序纸带的下一位，此时读写头上没有程序纸带。该截断指令执行后、下一条指令执行前会自动回到当前程序纸带的开头。

### 寻址

该机器支持回卷指令，执行后回退到数据纸带的开头,这让内存地址成为可能。

莫比奥尔斯机的IO系统由以下三个部分组成：MMin，MMcore，MMout。

- MMcore为计算核心，负责执行指令，兼任读写头的控制权流转控制
- MMin为输入端，负责接收按键输入
- MMout为输出端，负责将计算结果输出到屏幕

### 程序流转

![程序流转图](command_control.png)

如上述，指令带本身就是一个循环结构，头尾连在一起形成循环

其次，本机也有程序自生成的特性。程序操纵写完纸带后，纸带可以截断、转为程序、加入到程序序列中

### 输出控制

![输出控制图](output_control.png)

- 支持将数据纸带截断作为输出
- 此外，还支持从MMcore到MMout的流式输出

### 输入控制

![输入控制图](input_control.png)
这是较为特殊的一点。本机的输入控制不由MMcore中转。

需要输入时，MMcore主动把读写头控制权交给MMin，MMin按照约定直接写入数据纸带（一般是写8格），写完后读写头停留在dp+7位置，交还读写头控制权

# 莫比奥尔斯机编程语言

| 助记符 | 二进制    | 描述                                                                    | 虚拟机与理论实体机的区别              |
| :-- | :----- | :-------------------------------------------------------------------- | :------------------------ |
| `>` | `0000` | 数据读写头向右移动一格                                                           | 虚拟机移动读写头几乎无时间开销           |
| `<` | `0001` | 数据读写头向左移动一格                                                           | 虚拟机移动读写头几乎无时间开销           |
| `x` | `0010` | 翻转当前数据格（0变1，1变0）                                                      | 无                         |
| `f` | `0011` | 若当前格为0，正常执行下一条指令；若为1，跳过下一条指令（PC+2）                                    | 无                         |
| `s` | `0100` | 换带停机：挂起当前程序纸带，丢弃PC，切换到调度队列下一条程序纸带（新带从头读取）；数据纸带和读写头位置完全保留              | 无                         |
| `b` | `0101` | 将当前整条数据纸带从读写头右侧截断，取截下来的左侧数据纸带片段作为计算结果输出。不停机。                          | 无                         |
| `p` | `0110` | 截断快照：从读写头右侧截断，将截断的数据纸带片段作为新的程序纸带，插入到程序纸带序列中当前程序纸带的后一位                 | 无                         |
| `n` | `0111` | 空操作                                                                   | 断点调试器中也作为断点使用             |
| `l` | `1000` | **仅限程序纸带末尾**：运行到此指令，命令纸带自动折返                                          | 实体机纸带首尾相连形成闭环，虚拟机作用为PC归零  |
| `r` | `1001` | 回退指令，执行后回退到数据纸带的开头,这让内存地址成为可能。**注意，p可能使数据的位置发生变化，因为数据纸带截短导致原点变化**     | 虚拟机移动读写头几乎无时间开销           |
| `a` | `1010` | 阻塞式获取输入，定义为获取当前输入。结果为按键的ASCII编码，MMcore将读写头控制器交给MMin，MMin写8格后交还。仅支持单按键 | 虚拟机使用标准输入 `input()`，需回车确认 |
| `d` | `1011` | 与 a 类似，但非阻塞，定义为检测当前输入。若无按键，则为`11111111`                               | **暂未实现** — 当前虚拟机中此指令会报错   |
| `c` | `1100` | 发送当前读写头位置的一格二进制给MMout                                                 | 无                         |
| `!` | `1101` | 立即停机                                                                  | 无                         |

<br />

大小写敏感。不在指令集内的视为注释

如用\[?]表示读写头，示范如下

**b指令**：\
原始数据`1111 11[1]0 000`\
输出数据`1111 111`，即右侧被抛弃

**p命令**：
原始数据`0000 0111 011[1] 1000`\
输出代码`0000 0111 0111`，为`>nn`，剩余的数据纸带与读写头为`[?]1000`，此时因为读写头下方没有数据纸带，所以该条指令执行后、下一条指令执行前dp会自动置零（即回到数据纸带的开头），使得下一条指令执行前数据纸带与读写头为`[1]000`

\*\* a指令和d指令 \*\*

原始数据`1111 1111 [1]111`\
假设按下按键为`a`，则输出数据`1111 1111 0110 000[1]`，其中`01100001`为`a`的ASCII编码。

原始数据`[0]`
假设按下按键为`a`，则输出数据`0110 000[1]`

**d指令**

原始数据`[0]`
若无按键，则输出数据`1111 111[1]`

## 汇编期预处理特殊语法

| 符号                            | 用途                                           |
| :---------------------------- | :------------------------------------------- |
| (...)\*114514                 | 重复语法。在预处理时会进行展开，如将`(>)*1024`展开成1024个>        |
| (...)\*$REPEAT-NUMBER         | 带常量的重复语法                                     |
| (...)?1                       | 选择语法，选择该代码段是否被汇编进程序。后跟数字0/1                  |
| (...)?$ENABLE                 | 带常量的选择语法                                     |
| (...)?1\*114514               | 选择重复语法。必须?在前\*在后                             |
| (...)?$ENABLE\*$REPEAT-NUMBER | 带常量的选择重复语法                                   |
| #0                            | 程序纸带标注，出现在.mmlang和.mmbin当中,用于区分程序纸带。从0开始标号递增 |
| //                            | 注释，出现在.mmlang当中,用于注释代码                       |
| $XX-XXX=114514                | 定义常量，与\*重复语法结合使用。在文件开头定义，一行一个，仅限非负整数         |

除了`#0`外，其他不会被原样进入mmbin
