# 自定义数据纸带

编辑 `data_tape_maker.py`，修改 `make(dp)` 函数返回值即可改变初始数据纸带生成逻辑：

```python
# 返回斐波那契序列 parity
def make(dp):
    a, b = 0, 1
    for _ in range(dp):
        a, b = b, a + b
    return a % 2
```

默认返回全 0 数据纸带

# 利用r指令实现寻址
r指令的定义是回到数据纸带的开头，因此可以将r视为基值，实现基值-偏移值寻址，如`r>*1024`

你可以利用这个特性来实现栈和变量。甚至可以人为地划定数据区、变量区和栈区，使用r和>在他们间进行跳转


# fs妙用技巧

f指令只能跳过一条指令，不能跳过多条指令，这是f指令的一个限制。但是，我们可以将f和s指令结合使用，变相绕过这个限制

## 实现指定程序纸带切换

```
#0
r>*1024fs ...
#1
r...
```

s指令的天然限制是默认只能切换到队列下一条程序纸带，但是我们可以利用特定的标记位和fs指令来实现切换到指定程序纸带的功能

在这个程序中，我将数据纸带的1024位视为标记位，如果数据带的1024位为1，则切换到程序纸带1，否则继续执行当前程序纸带

这样就实现了切换到指定程序纸带的功能。

# 利用p指令实现GC

假设当前数据纸带和读写头如下：`[0]00011111`，如果我们想要抛弃前面的一堆0，我们可以利用p指令，把数据纸带裁切并加入程序纸带序列，从而清除前面的0

```
#0
>x>>>
p
```

因为p指令会把当前数据纸带片段视为程序，因此我们需要将当前纸带前四位设为`0100`(s)，执行到时立即换带，从而保护后面的混沌数据不被解析

实际上，它不应完全被视为GC，因为它只是把数据纸带裁切并加入程序纸带序列，并没有清除占用

注意，它会破坏数据纸带原点，导致基于r指令硬编码的寻址失效，需要手动处理
